# MySafeFob (MSF) — firmware `src/`

Skeleton of the application firmware (Phase 8). Air-gapped password manager +
TOTP authenticator for the XTEINK X4 Pro (ESP32-S3). Decisions locked in:
see `docs/ROADMAP.md` (ADR-001 to ADR-008), `docs/FEATURES.md`,
`docs/INTERFACES.md`.

## Structure

```
src/
├── CMakeLists.txt          # root — board selection -DMSF_BOARD=x4pro
├── sdkconfig.defaults      # settings common to all boards
├── main/                   # main app (hello world + console REPL)
├── components/
│   ├── totp_engine/        # RFC 6238 TOTP engine (copied from the validated Phase 4 test)
│   ├── secret_store/       # encrypted keystore — CONTRACT + stub (task 8.2)
│   └── esp3d_log/          # application logging (PiBot port — hooks -> UI)
├── boards/
│   ├── x4pro/              # actual board (config + README, full bring-up)
│   │   ├── partitions.csv  #   16 MB table specific to the board (ADR-007):
│   │   │                   #   fixed, contractual offsets
│   │   ├── factory/        #   STANDALONE sub-project per board (PiBot
│   │   │                   #   alignment): recovery app + bootloader hook.
│   │   │                   #   Dedicated hardware drivers (UC8279/GT911/SDMMC) —
│   │   │                   #   see ../docs/FACTORY.md. Each future board carries
│   │   │                   #   ITS OWN factory (no shared core).
│   │   ├── build_scripts/  #   build_one.py <app|factory|all> [--clean]
│   │   │                   #   (PiBot port — auto-configured IDF env)
│   │   ├── flash_scripts/  #   one-click .bat files: flash_all / flash_app /
│   │   │                   #   flash_factory / erase_flash [COMx]
│   │   ├── cmake/          #   postbuild.cmake -> feeds installer/
│   │   │                   #   + copy_if_exists.cmake (factory artifacts)
│   │   └── factory/cmake/  #   factory postbuild -> installer/x4pro_factory/
│   └── m5paper_mono/       # documentation stub (ADR-008, no code)
├── tools/
│   ├── build_scripts/      # build_mgr.py (multi-board, interactive + memory)
│   │                       # + gen_ota_initial.py (otadata -> boot app0)
│   └── flash_scripts/      # flash_mgr.py (interactive + memory, flash map
│                           # JSON per variant, consumable by web installer)
└── installer/              # generated by the postbuild steps (gitignored)
    ├── x4pro_app/          #   firmware + factory + bootloader hook + pt + otadata
    │                       #   (+ x4pro_app.json = flash map)
    └── x4pro_factory/      #   rescue: factory + bootloader hook + pt + otadata 0
```

**Structural rule** (PiBot alignment): everything hardware-dependent
lives under `boards/<board>/`. The factory is a recovery tool — it must
stay minimal, self-contained, and tested as-is: duplication (gfx/menu)
between boards is accepted rather than a shared core that could break
several boards at once. Same logic applies to build_scripts/flash_scripts.

## Quickstart (IDF 5.5.5 — no environment to activate)

**A single interface, a single memory** (PiBot port):

```bash
cd src

# BUILD — interactive with memory (Enter = rerun the last choice)
python tools/build_scripts/build_mgr.py
# or via CLI:
python tools/build_scripts/build_mgr.py --build_all          # factory first
python tools/build_scripts/build_mgr.py --build_variant app  # or factory

# FLASH — interactive with memory (variant/port/baud auto-detected)
python tools/flash_scripts/flash_mgr.py
# or via CLI:
python tools/flash_scripts/flash_mgr.py --variant x4pro_app --port COM5
python tools/flash_scripts/flash_mgr.py --variant x4pro_app --app-only --port COM5
python tools/flash_scripts/flash_mgr.py --variant x4pro_factory --port COM5
```

**Or double-click** the `.bat` files in `boards/x4pro/flash_scripts/`
(port as argument, default COM5) — same flash_mgr engine.

**With the VS Code ESP-IDF extension**: open `src/` (app) or
`src/boards/x4pro/factory/` (factory) → Build / Flash / Monitor.
⚠ The app's Flash button flashes the **bootloader without the hook**
(no recovery) — the correct bootloader comes via `flash_all` / `flash_factory`.

**Under Git Bash**: idf.py 5.5 refuses MSYS → the tools above handle it
(the env is cleaned up internally), or use the .bat files, or
`boards/x4pro/factory/msf_build.bat` (cmd wrapper).

Then `idf.py -p COM5 monitor`: MySafeFob banner + `msf> ` console
(commands `help`, `about`, `totpselftest`).

## Critical contracts (do not break)

| Element | Value | Where |
|---|---|---|
| Backup otadata | offset `0xB000`, magic `0xAA55AA55` | `boards/x4pro/factory/bootloader_components/custom_bootloader/hooks.c` + `boards/x4pro/factory/main/main.c` |
| Partition table | offset `0xC000`, factory @`0x20000` | `boards/x4pro/partitions.csv` + `boards/x4pro/sdkconfig.defaults` |
| Store/export magics | `MSF1` (blob), `MSFS` (internal cleartext), `MSFEX1` (SD export) | `docs/INTERFACES.md` + future `secret_store.c` |
| Recovery boot | **Power = GPIO3** button held ≥ 10 s (GPIO0 = strapping; Power+Right combo abandoned, ADR-009 amendment 2026-09-16) | `hooks.c` |
| Application log | esp3d_log (level `-DMSF_LOG_LEVEL=`, default 3=debug); board drivers stay on `ESP_LOG*` | `components/esp3d_log/`, root `CMakeLists.txt` |
| App UI | **FreeInkUI** (native ESP-IDF port from `freeink-sdk`, MIT) replaces LVGL — see ADR-010 (`docs/ROADMAP.md`) | `docs/ROADMAP.md` §ADR-010, prototype `references/test_apps/freeinkui-poc/` |
